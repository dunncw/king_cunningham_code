# docs

Versioned project documentation that lives in the repo — architecture notes,
stable workflow specs, onboarding guides. Put a doc here when it should be
shared and tracked.

Not here:

- `task/` — local scratch for in-progress specs and working notes. Git-ignored,
  never committed.
- `.claude/` — Claude Code context files (build, packaging, testing notes).
- per-module `CLAUDE.md` — module-specific docs live beside their code in
  `src/<module>/`.
